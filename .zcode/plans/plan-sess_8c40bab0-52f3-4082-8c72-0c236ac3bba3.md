# 代码块预览卡片（HTML 预览 / Mermaid / SVG）

目标：```html → 沙箱 iframe 预览、```mermaid → 图表、```svg → 图片渲染；卡片带标题栏（折叠箭头 + 标题 + 右上角「...」菜单：查看代码/预览切换、复制代码、下载）。仅这三种语言升级为卡片，普通代码块保持现状；卡片默认展开预览。「保存为图片」不做。

## 整体方案：renderer 输出骨架 + 完成后水合

绕开 DOMPurify 会剥 iframe 的限制：marked renderer 只输出安全的占位骨架（代码以转义文本放在卡片内），消息渲染完成后再把水合逻辑跑一遍注入 iframe/SVG。流式期间不水合，避免半截代码反复重建 iframe。

## 改动清单

### 1. 新增 `src/web/public/scripts/app/chat/code-block-preview.js`
核心模块，导出 `enhanceCodeBlocks(root)`：
- 水合：遍历 `root` 内 `.code-preview-card:not([data-hydrated])`，按 `data-code-lang` 分发：
  - `html`：创建 `<iframe sandbox="allow-scripts">`，`srcdoc` 取卡片内代码文本；
  - `svg`：代码转 base64 填 `<img src="data:image/svg+xml;base64,...">`（img 内脚本不执行，天然安全）；
  - `mermaid`：首次遇到时动态插入 `<script src="vendor/mermaid/mermaid.min.js">` 懒加载（仓库无动态加载先例，此处自建；~2.8MB 不进首屏），按当前 `data-theme` 选 dark/default 主题，`mermaid.render()` 输出 SVG 注入；渲染失败回退显示代码视图+错误提示。
- 菜单逻辑：模块内自管 document click 关闭（不挂 create-app 分发链，保持自治），点击「...」toggle `.open`；菜单项：
  - 查看代码 / 查看预览：切换卡片 `.show-code` class；
  - 复制代码：复用现有复制反馈模式（按钮变「已复制」）；
  - 下载：Blob 下载 —— html → `.html`（源码即产物）、mermaid → 渲染后的 `.svg`、svg → `.svg`。
- 标题提取：html 取 `<title>`，mermaid 取第一行注释/图类型（如 `graph TD` →「流程图」映射不做，直接用「Mermaid 图表」），取不到用兜底文案。

### 2. 修改 `src/web/public/scripts/app/markdown.js`
- `markedRenderer.code`（83-97 行）：`lang` 精确匹配 `html`/`mermaid`/`svg` 时输出卡片骨架 `<div class="code-preview-card" data-code-lang="...">`（标题栏：chevron SVG + 标题 + 「...」按钮含下拉菜单 + 预览容器 + 内含转义代码的 `<pre class="code-preview-source">`），流式半截 lang（`ht`/`htm` 等）不匹配，自然走原有 pre/code 分支。
- 骨架只用标准标签和 data-* 属性，DOMPurify 默认放行，无需改 sanitize 白名单。

### 3. 水合挂载点（3 处）
- `src/web/public/scripts/agent-loop.js`：`renderAnswer()`（约 352 行，紧跟 enhanceLocalFileLinks/hljs）、「展开完整内容」回调（375-379）、`renderProcessTextSegment` 非流式完成分支（494-497）。流式 `renderStreamingAnswer` 不挂载。
- `src/web/public/scripts/app/chat/message-renderer.js`：`renderAssistantText()`（26-30 行，enhanceLocalFileLinks 旁），覆盖非流式 provider 和历史回放。
- agent-loop.js 是传统 IIFE，经 `window.AnyBotMarkdown` 同款方式暴露 enhance 函数给它用（main.js 注册）。

### 4. 菜单/复制事件
沿用 `message-list-controller.js:30-41` 的现有 click 委托，追加 `.code-preview-menu-btn` / `.code-preview-option` 分支，一次绑定覆盖全部渲染路径。

### 5. 样式 `src/web/public/styles/chat.css`
紧跟现有 `.code-header` 区块（1141-1192 附近）新增，全部用现有主题变量自动适配明暗：
- `.code-preview-card`：`var(--code-bg)` 底、`var(--border)` 边框、10px 圆角（同现有 pre）；
- 标题栏：`var(--code-header-bg)`，chevron 内联 SVG + `[open]`/`show-code` 旋转（参考 change-review.css:225-236）；
- 「...」图标新写（三个 circle，stroke=currentColor 风格，项目无现成实现）；
- 下拉菜单：复刻 `.branch-dropdown`/`.branch-option` 模式（`--popover-bg`、16px 圆角、translateY 过渡、hover `--sidebar-hover`），向下弹出；
- 预览区：iframe/img 白底容器（HTML/SVG 多为白底设计，避免暗色主题下看不清），mermaid 跟随主题。

### 6. vendor Mermaid
`npm pack mermaid`（或 node_modules）取 `dist/mermaid.min.js` 放入 `src/web/public/vendor/mermaid/`，更新 vendor README。不进 index.html，按需加载。
